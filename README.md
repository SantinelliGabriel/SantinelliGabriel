## Proyecto destacado

### [Automatizador de comprobantes e informes de IVA](https://github.com/SantinelliGabriel/automatizador-reportes)

Un proyecto personal que conecta mi experiencia contable con la programación:

- Procesa archivos Excel, CSV y PRN, incluidas exportaciones de ARCA y plantillas Holistor.
- Valida CUIT, períodos, importes y duplicados; separa los registros que necesitan revisión.
- Genera informes Excel con resúmenes y observaciones mediante pandas y openpyxl.
- Conserva un historial por cliente y período en SQLite, con importes almacenados en centavos.
- Incluye una CLI, una interfaz Streamlit y una demo con datos sintéticos.
- Cuenta con pruebas con unittest y controles de Ruff y GitHub Actions para Windows y Linux.

Es una herramienta de apoyo a la revisión: no se conecta directamente a ARCA ni presenta declaraciones.
